# AI-Document-Ingestion-Pipeline-legal-

An evaluation-driven AI document intelligence pipeline that extracts structured information from commercial contracts using the [CUAD dataset](https://www.atticusprojectai.org/cuad/).

- Analysis of CUAD: <https://arxiv.org/abs/2103.06268>
- Code for replicating the results and the trained model: <https://github.com/TheAtticusProject/cuad>


The project explores document parsing, LLM-based clause extraction, schema validation, and evaluation techniques, with a focus on **engineering tradeoffs, measurable performance, and reproducibility**.

The resulting repository serves as both a functional implementation and a technical case study demonstrating practical AI engineering skills.
